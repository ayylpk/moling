# 类型（题材）

一个类型 = 这个题材的**世界观规则**与**叙事套路**。它回答：这个世界有什么、冲突从哪来、
读者对这个题材期待什么。

它**不回答**"用什么语气写"——那是文风的事。

## 生效优先级

类型片段是题材约束，不是剧情草稿。它可以规定冲突边界、因果方式、读者预期和常见失误，
但不能覆盖世界观圣经、角色卡、地点卡、章纲或裁决结果中的具体事实。与事实冲突时，保留事实，
再用本类型允许的方式表达。

新增类型时，优先补 `writer.md` 与 `polisher.md`，再按需要补其他 agent 的片段。片段应写成
可执行的规则和可检查的反例，避免只写“有电影感”“更宏大”等不可执行形容词。

## 每种类型下按 agent 分文件

| 文件 | 注入给 | 说的是 |
|---|---|---|
| `story-planner.md` | 世界观 agent | 这个题材该怎么立规则、代价长什么样 |
| `character.md` | 角色 agent | 这个题材的典型人物位与冲突来源 |
| `location.md` | 地点 agent | 这个题材的地点长什么样、可辨识度从哪来 |
| `architect.md` | 架构师 agent | 这个题材的卷结构与节奏怎么排 |
| `actor.md` | 裁决 agent | 这个题材里"两难"通常是什么形式 |
| `writer.md` | 执笔 agent | 这个题材的场面怎么写、要注意什么 |
| `polisher.md` | 润色 agent | 这个题材的套话最容易出现在哪 |

缺哪个文件就跳过哪个——**片段是可选的，不是必填的**。
