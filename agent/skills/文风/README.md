# 文风

一种文风 = **语气、句式、节奏、距离感**。它回答：同一件事，用什么声音讲出来。

它**不回答**"这个世界有什么"——那是类型的事。文风不该引入任何题材家具
（写冷峻不等于写悬疑，冷峻的都市和冷峻的武侠是两种东西）。

## 与类型的关系

两者正交，可以任意组合：
- 冷峻 + 都市 = 现实题材的克制笔法
- 冷峻 + 悬疑 = 冷调的推理
- 激烈 + 都市 = 市井里的冲突

## 每种文风下按 agent 分文件

| 文件 | 注入给 |
|---|---|
| `story-planner.md` / `character.md` / `location.md` / `architect.md` / `actor.md` / `writer.md` / `polisher.md` | 对应 agent |

文风片段一般**只对 writer 与 polisher 有意义**（它们直接产出文字）。
给其他 agent 的文件是可选项，通常不需要。
